# 🧩 افهم مصروفي اليومي

## خريطة التطبيق

- **HTML** يعرّف العناصر. خاصية `id` تعطي العنصر اسمًا يمكن الوصول إليه.
- **CSS** يحدد الشكل. غيّر لون `#087f6c` لتخصيص اللون الرئيسي.
- **JavaScript** يقرأ المدخلات، يحدّث البيانات ثم يعرض النتيجة.
- ربط الملف باستخدام `defer` يجعل الكود يبدأ بعد قراءة عناصر الصفحة.

## كيف تتبع الكود؟

1. ابحث عن `querySelector` لترى العناصر التي يستخدمها التطبيق.
2. ابحث عن `addEventListener` لتعرف ما الذي يحدث عند النقر أو الإرسال.
3. اقرأ الدوال والتعليقات العربية، ثم جرّب تغيير قيمة واحدة.
4. `preventDefault()` يمنع إعادة تحميل الصفحة عند إرسال النموذج.
5. `textContent` يعرض النص بأمان دون تفسيره ككود HTML.

## المفاهيم

- reduce لحساب المجموع
- تحويل الريالات إلى هللات صحيحة
- JSON وlocalStorage

## تدريب عملي

1. غيّر عنوان الصفحة.
2. غيّر اللون والمسافات في CSS.
3. اشرح لشخص آخر ماذا يحدث بعد الضغط على الزر الأساسي.
4. أضف تصنيفًا مثل طعام أو مواصلات، ثم اجمع كل تصنيف.
5. اختبر تعديلك بإدخال صحيح وآخر خاطئ.

`const` لمتغير لا نعيد إسناده، و`let` لمتغير يمكن إعادة إسناده. `function` تجمع خطوات نعيد استخدامها.

لا تحتاج لحفظ الكود. الهدف أن تفهم المدخلات والنتيجة وتستطيع تعديل السلوك. قدّم المشروع كتدريب تعلّمي، ولا تدّعِ إتقانه قبل أن تستطيع شرحه.
